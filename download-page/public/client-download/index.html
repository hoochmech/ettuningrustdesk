ET Tuning Remote

Remote support client for East Texas Tuning customers

Download for Windows

Windows 10 or 11, 64-bit

How to install

  1. Click Download for Windows and open the file once it finishes downloading.
  2. If Windows shows a "Windows protected your PC" message, click More info, then Run anyway.
  3. Follow the installer, click Install, and accept the prompt asking to allow changes to your device.
  4. Open ET Tuning Remote and read your ID and password to your East Texas Tuning technician so they can connect.
